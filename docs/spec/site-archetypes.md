# Site archetypes

Archetypes are recipes, not separate frameworks.

- Professional services: Home, Services, About, Contact.
- Clinic: Home, Services, Professionals, Location, Contact, Privacy.
- Restaurant: Home, Menu, About, Location, Reservations.
- School: Home, Programs, Admissions, About, Contact.

Projects select and adapt only the pages justified by verified user needs and content.
