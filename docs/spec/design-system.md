# Design system

The foundation owns role-based tokens, typography and spacing scales, layout widths, responsive rules, surfaces, focus treatment, controls, forms, section rhythm, image treatment, borders, shadows, and motion rules. Client identity owns verified logos, colors, licensed typography, photography, voice, and project-specific composition.

Tokens describe roles such as `--color-brand`, never incidental appearances such as `--blue`. The base is mobile-first, content-driven, accessible, restrained, and neutral enough to avoid imposing a recognizable template aesthetic. System fonts are the default; client fonts should be licensed and self-hosted when practical.

Avoid generic AI-site conventions, ornamental gradients, gratuitous glass effects, meaningless cards, fabricated metrics, and motion without a user purpose. Visual uniqueness should primarily come from tokens, typography, real imagery, spacing, composition, and content.
