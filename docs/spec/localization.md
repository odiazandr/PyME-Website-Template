# Localization

The default locale is `es-MX`. Multilingual routing, translated metadata, hreflang, navigation, content review, and per-language QA are enabled only when a verified requirement exists.

Machine translation is not silently presented as approved business content. Each locale is reviewed as a complete user experience.
