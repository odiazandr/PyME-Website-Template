# Product scope

The foundation serves Class A informational and marketing sites and Class B sites extended with reviewed managed services. Typical content includes company information, services, menus, teams, locations, hours, galleries, testimonials, FAQs, contact paths, maps, and privacy information.

Accounts, custom authentication, private dashboards, live inventory, portals, custom commerce or booking engines, marketplaces, and persistent application state are Class C. The public marketing layer may remain, but application architecture requires separate review.

Universality means a strong core plus extension contracts—not preinstalling every possible capability.
