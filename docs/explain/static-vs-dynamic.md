# Static versus dynamic

A static site publishes already-built files to a CDN. That is enough for most public business information and removes servers, databases, accounts, and many failure modes. Dynamic behavior is added when a real requirement needs private computation or current state—not because the framework makes it possible.

Canonical policy lives in `docs/spec/architecture.md` and `docs/spec/product-scope.md`.
