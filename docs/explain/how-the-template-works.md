# How the foundation works

The canonical repository is a product blueprint. A client receives an independent copy, verified business facts and a distinct identity, while inheriting stable rules for architecture, quality, deployment, and maintenance. The site remains simple at runtime because operational complexity lives in documentation and validation.

Canonical policy lives in `PROJECT.md` and `docs/spec/`.
