# ADR 0002: Hard memory contracts

Status: accepted.

Require explicit authority, ownership questions, lifecycle state, index coverage, and template/project modes. Documentation without enforceable boundaries silently accumulates duplicates and dead pointers; unavailable validation is reported honestly as unverified.
