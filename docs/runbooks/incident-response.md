# Incident response

Classify impact and urgency; contain the issue without destroying evidence; rotate exposed credentials; restore a known-good source, deploy, DNS state, or integration; verify public behavior and data handling; notify the appropriate owner; then record cause, remediation, and prevention proportionately.
