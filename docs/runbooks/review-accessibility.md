# Review accessibility

Run available automated checks, then manually test document language, landmarks, headings, keyboard order, visible focus, menus, forms and errors, zoom, contrast, touch targets, image alternatives, reduced motion, and representative mobile widths. Record limitations; do not claim certification from automation.
