# Create a client site

Create a private repository from the template; generate a stable site UUID; record repository metadata, locale, canonical-domain status, and template version; switch memory to project mode; populate verified business facts; customize brand and information architecture; then use previews and production gates. Provisioning external accounts is outside this repository.
