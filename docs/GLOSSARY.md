# Glossary

**Canonical owner** — The single active source authorized to define a durable fact.

**Client site** — An independent repository created from this foundation for one business.

**Class A** — Informational or marketing website within the default architecture.

**Class B** — Business website with reviewed managed-service extensions.

**Class C** — Web application requiring a separate architecture review.

**Integration** — A third-party service, script, iframe, API, or hosted workflow connected to a site.

**Managed service** — An external provider used before creating equivalent custom infrastructure.

**Project mode** — Adopted client-repository mode in which unresolved distribution placeholders are invalid.

**Project 1** — This PyME Website Foundation and the client websites produced from it.

**Project 2** — A future, independent portfolio operations dashboard that may observe websites but is never required by them.

**Site ID** — A stable, non-secret UUID generated once for a client site.

**Template mode** — Canonical distribution mode in which defined template placeholders are permitted.

**Template version** — The SemVer release of the foundation adopted by a client site.

**Working Set** — Optional local pointers to task-relevant sources; never a source of truth.
